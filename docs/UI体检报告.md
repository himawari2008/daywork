## 二、"单调死板"的真根因（反直觉）

不是"没变化"，而是**同一撮死值到处重复 → 扁平雷同**：
- 26rpx 出现 53 次、22rpx 53 次、24rpx 51 次、28rpx 46 次……全站就靠这 handful 值撑着，层次拉不开。
- 331 处硬编码色值意味着**没有单一真相源**：想统一调一个强调色，得改 331 个地方，改不全就"这里改了那里没改"——这正是你觉得"改不好"的来源。

**结论：死板 = 设计系统没被用起来 + 复制粘贴的同质化。** 治法是"收口到 token"，不是"再加花样"。

---

## 三、"改了好久改不好"的真根因

1. **单页 60KB wxss** → 选择器特异性冲突高发，样式不生效时极难定位（你大概率就栽在这）。
2. **硬编码值散落 331 处** → 改动无法联动传播，A 处修了 B 处还是旧值。
3. **双重点点 bug** → 两套 indicator 同屏，就是典型的"复制粘贴没删干净"留下的可见破绽（已修）。
