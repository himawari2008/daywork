# 活记 · 小程序 UI 改进计划（快速上线 + 获取用户版）

> 视角：UI Designer / 产品体验
> 日期：2026-07-17
> 依据：现有代码 `daywork/miniapp`（活记 v4/v5）、`daywork/docs/PRD.md`
> 目标：在不重写的前提下，**最快速度上线**，并用**第一印象 + 分享传播**两条杠杆拿到第一批用户与留存。

---

## 0. 一句话结论

活记的**设计底子已经很好**（暖色有机极简、暗色模式、CSS 纯图标、情绪色、热力图都齐了），不需要推倒重来。要快速上线并获客，重点是三件事：

1. **砍掉 V2 负担**——把实验页和"我的"里的 V2 模块从首发路径里摘出来，减少 QA 面、让价值主张更锐利。
2. **守住"3 秒界面"**——首页必须让"张嘴就记"成为唯一焦点，时间线作为"奖励"在记完之后才浮现。
3. **把分享做成增长引擎**——个人数据 → 可分享的美图卡片，是这款产品零投放获客的唯一正循环，必须做成一等公民。

---

## 1. 当前诊断（基于实代码）

| 维度 | 现状 | 评价 |
|------|------|------|
| 设计系统 | `app.wxss` 已有完整 token（暖白/墨色/珊瑚/品牌/状态/情绪/热力），含暗色模式 | ✅ 优秀，直接复用 |
| 引导页 | `pages/onboarding` 3 页滑动 + 动画 CSS 图标（声波/大脑/书），强第一印象 | ✅ 好；有 1 处冗余（自定义 dots 与 swiper 原生 indicator 重复） |

| 我的页 | `pages/mine` 极丰富：连续环/热力图/心情河流/AI周报/借支/名片/分组树 | ⚠️ 功能溢出，V2 内容混入 V1 |
| 实验页 | `loans`/`card`/`doodle` 已写进 `app.json` 且可被跳转 | ⚠️ 首发风险与 QA 负担 |
| TabBar | 记 / 问 / 我的，图标齐全（`images/` 6 张 png 均在） | ✅ 可用 |

## 2. 改进原则（对齐 PRD）

- **3 秒界面**：第 1 秒"这是新的"（干净大留白）→ 第 2 秒"张嘴就行"（中央语音键）→ 第 3 秒"我的东西在这"（流式卡片）。任何改动不能破坏这条线。
- **回报驱动**：每次记录必须即时看到反馈（今日 N 条 / 相关主题 / AI 关键信息）。UI 要把"回报"放大，把"操作"藏好。
- **零模板零模式**：界面不要出现"记工模式/笔记模式"这类选择，用户只是在说话。

---

## 3. 四阶段计划

### 阶段 0 — 发布前体检（P0，1–2 天，必须做）

**目标：把首发包缩到最小、最稳。**

- **摘出实验页**：`app.json` 的 `pages` 移除 `loans/card/doodle`（保留代码，仅从发布入口与跳转移除）；或加一个 `isLab` 开关，藏在"我的 → 关于"里。减少真机测试面。
- **"我的"做减法**：把 `借支管理`、`职业名片(卡片)`、`分组管理树`、`AI 周报` 移出 V1 主路径（保留实现，入口收到"更多/实验室"）。V1 的"我的"只留：连续环 + 三统计 + 往年今日 + 心情河流 + 主题切换。更聚焦 = 更快 QA。
- **空状态体检**：逐页确认 0 数据时布局不破（`index` 时间线、`chat`、`mine` 都已部分有；补 `index` 首屏空态）。
- **Tab 对齐 MVP**：`问`(chat) 若 AI 搜索未达 V1 标准，临时改为"问（预览）"或先隐藏，避免首屏承诺未兑现的功能。

> 涉及：`app.json`、`pages/index/index.js`、`pages/mine/mine.wxml`(+`.wxss`)、`pages/onboarding`（删冗余 dots）。

---

### 阶段 1 — 3 秒留存（P1，2–3 天，最高杠杆）

**目标：让新用户 30 秒内完成第一次记录，并想回来。**

- **首页英雄化语音键**：首屏（尤其无记录时）让"按住说话"成为唯一视觉焦点，时间线/抽屉退为次要。无记录时空状态写一句温暖 CTA："按住，说点什么 →"，而非空白。
- **首记庆祝微交互**：AI 解析完成、生成确认卡片后，给一个轻量"回报"动效（情绪色光晕 / 一句"已为你记下"），把"任务"变"奖励"——这是复记的核心钩子。
- **即时反馈条**：首页顶部常驻"今日已记 N 条 · 连续 M 天"，每次记录 +1 有数字跳动。把 PRD 的"每次记录必须有即时反馈"做成可见、可感。
- **引导页去冗余**：删 swiper 原生 `indicator-dots`，只保留自定义可点 dots（现有 wxss 已注释说明重复）。

> 涉及：`pages/index/index.wxml`(+`.wxss`)、`pages/onboarding/onboarding.wxml`(+`.wxss`)、`detail` 确认卡片完成态。

---

### 阶段 2 — 分享传播引擎（P2，3–5 天，获客主引擎）

**目标：让老用户主动把活记"晒"出去，带来新用户。**

- **统一分享卡片组件**：做一张 on-brand 的分享图（canvas 生成 PNG），样式复用现有 token（珊瑚/暖白/情绪色/热力）。模板：
  - 月度洞察卡（热力图 + 情绪河流 + 高频主题）
  - 年度回顾卡（PRD 的 V2 卖点，提前做轻量版）
  - 职业名片卡（已有 `card` 页，升级为可生成分享图）
- **一键分享**：每个"回顾"入口（往年今日 / 随机回顾 / 心情河流 / 统计）都带"分享"按钮，调 `wx.showShareMenu` + `onShareAppMessage` 带图。
- **分享落点优化**：分享卡片点开 → 引导"也来记一笔"的极简落地页/引导，形成闭环。

> 涉及：新增 `components/share-card`（或 `pages/share`），复用 `app.wxss` token；`mine` 各回顾区块加分享入口；`card` 页升级。

---

### 阶段 3 — 一致性 & 无障碍 & 手感（P3，持续，品质信号）

**目标：让产品"贵"起来，留住人。**

- **无障碍对比度**：对 `--ink-soft`/`--ink-faint` 小字做 WCAG AA 审计；不足处加深或加大字号。目标：正文 4.5:1、大文本 3:1。
- **触控目标 ≥ 44px**：日历日格、标签云、筛选 chip 确保可点区域达标（rpx ≥ 88）。
- **暗色模式对等**：抽查各页暗色变量是否真正生效（重点 `mine` 新模块、`detail`）。
- **动效降级**：为 `prefers-reduced-motion` 提供关闭开关（现有 onboarding 声波/星火动效加 class 降级），照顾前庭敏感用户。
- **骨架屏补齐**：`index` 时间线加载时也用 `mine` 已有的 skeleton 风格，避免空白闪。
- **组件化收口**：把按钮/卡片/标签/空态沉淀为 `app.wxss` 里的统一 class，后续页面直接复用，防止设计债。

> 涉及：`app.wxss`（加 a11y token + 通用组件类）、各页小修、`pages/index` 骨架屏。

---

### 阶段 4 — 性能与重量（P4，按需）

- **首页瘦身**：`index.wxss` 60KB 单页偏大；长时间线改用虚拟列表（`wx:for` 分段渲染），抽屉/日历滑入时再渲染。
- **首屏优先**：引导 → 首页首屏（语音键+空态）必须 < 1s 可交互；重模块（热力图/心情河流）延后加载。
