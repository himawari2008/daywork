# 活记 UI 品牌物料交付清单

**活记** = 个人 AI 语音工作日记小程序（为家航旗下产品）。
本目录所有物料均使用活记专属视觉语言：**日记卡 + 声波 + AI 火花**，不使用为家航的「航小匠」吉祥物与指南针。

## 设计令牌（来自《为家航_品牌视觉规范》第四~六章，活记共用）

- 主色 航橙 `#E8815C`（橙色强调用更深的 `#D07050` 以保证 WCAG AA 对比度）
- 正文深墨 `#1A1A1A`
- 按钮 24rpx 圆角；卡片白底 16rpx 圆角浅阴影
- 间距 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40rpx

## 无障碍要点

- 白字直接压 `#E8815C` 仅 2.84:1，不达标；故正文用深墨、橙色强调用 `#D07050`。
- 所有图标无文字依赖，缩放后保持可识别。
